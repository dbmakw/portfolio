## Cybersecurity Projects

### 1. Web Security Header Auditor
Checks common HTTP security headers including CSP, HSTS, X-Content-Type-Options, Referrer-Policy, Permissions-Policy, and X-Frame-Options.

[View project](projects/web-security-header-auditor/)

### 2. SOC Log Anomaly Detector
Parses SSH authentication logs, counts failed login attempts by source IP, and highlights sources above an analyst-defined threshold.

[View project](projects/soc-log-anomaly-detector/)

### 3. DFIR File Hash Triage
Recursively calculates SHA-256 hashes for evidence files and compares them with locally supplied IOC hashes, exporting results to CSV.

[View project](projects/dfir-file-hash-triage/)
